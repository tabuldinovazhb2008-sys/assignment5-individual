## About the Project
In this project, I created five interactive JS tasks on a webpage with a soft pink layout.

- Task 6: An interactive counter where you can increase, decrease, or reset the number. It does not go below zero.
- Task 7: A text box that instantly mirrors whatever you type, shows the current character count, and has a clear button to reset everything.
- Task 8: A select dropdown that lets you switch between three images (cat.jpg, paris.jpg, rose.jpg) and updates their alt text and captions dynamically.
- Task 9: An input field that listens to key presses. Pressing enter submits the typed text, and pressing escape clears it.
- Task 10: An interactive card that highlights when you hover over it with the mouse or focus on it using the Tab key.
